Straight answers

What is ready today, and what is not.

It is pre-1.0. Here is the honest list.

Ready today

  • The operating system, with no shell, checking itself at every start.
  • An approved list for everything that leaves.
  • A step log, so a crash repeats nothing.
  • A tamper-proof record of what started up and where it connected.
  • A locked sandbox for the tools agents use.

Not built yet

  • Running agents end to end: the built-in agent loop arrives with the current release.
  • Signing every action arrives with the current release.
  • Cloud installs: guides are written; tested so far on our own servers only.
  • Hosted AI models: not tested yet; open models run today.
  • Hiding data from the host operator: Not yet — on our roadmap.
  • Certification: There are no certifications yet.
  • Signing keys: this version uses development signing keys.
