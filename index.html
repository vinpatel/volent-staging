How it works

Three things it does for you.

It runs your agents inside one sealed machine, on servers you choose.

Nothing leaves unless you said so.

Every request goes through one guarded door. A place not on your list is turned back, and the reason is written down.

Nothing happens twice.

Each step is written down before it runs. After a crash, the agent skips what is done and finishes the rest.

You can prove what ran.

The machine signs what it started with and where it connected. Your auditor checks it on their own computer.

Check it yourself

Straight answers

What is ready today, and what is not.

It is pre-1.0. Here is the honest list.

Ready today

  • A sealed machine that checks itself every time it starts.
  • One guarded door for everything that leaves.
  • A logbook, so a crash does not repeat an action.
  • A signed receipt of what started up and where it connected.

Not built yet

  • Signing every action arrives with the current release.
  • Hiding data from the host operator: Not yet — on our roadmap.
  • Certification: There are no certifications yet.
  • Signing keys: this version uses development signing keys.
