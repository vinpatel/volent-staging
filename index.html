Straight answers

Ready today. Coming next.

An early version (pre-1.0). The honest list.

Ready today

  • The computer itself, which checks itself every time it starts.
  • An approved list for everything that leaves.
  • A step log, so a crash repeats nothing.
  • A tamper-proof record of what started up and where it connected.
  • A locked box for the tools agents use.

Not built yet

  • Agents doing a whole job on their own: the built-in agent loop arrives with the current release.
  • Signing every action arrives with the current release.
  • Cloud installs: guides are written; tested so far on our own servers only.
  • Paid AI models (like the big chat services): not tested yet; free open models run today.
  • Hiding data from whoever runs the server: Not yet — on our roadmap.
  • Certification: There are no certifications yet.
  • Signing keys: this version uses development signing keys.
